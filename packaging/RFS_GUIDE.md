# Debian RFS (Request for Sponsorship) — after Mentors upload

File this only after:
- Debian has assigned [ITP #1154410](https://bugs.debian.org/1154410) (complete);
- source and binary packages pass lintian and a clean Debian unstable build;
- the source is signed using the PERSONAL OpenPGP key registered on Mentors;
- the dput mentors source upload succeeds and appears on Debian Mentors.

Debian Mentors provides an RFS template on the package page.
Use that template with ITP #1154410, and include the verified Mentors .dsc link. Do not close the ITP manually; the initial archive upload is intended to close it via the changelog.

Example subject:
RFS: brightery-doctor/1.2.0+ds-1 [ITP] -- read-only Linux server health dashboard

https://mentors.debian.net/sponsors/rfs-howto/

Include a summary of testing, any lintian findings, and the source
package URL. A sponsor must review and upload it to Debian.
