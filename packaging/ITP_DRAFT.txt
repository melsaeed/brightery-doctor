  Description     : read-only Linux server performance diagnostic dashboard

 Brightery Doctor collects bounded Linux /proc and /sys samples to
 identify possible CPU I/O wait, disk queue and write-latency pressure,
 memory pressure, and unusually blocked processes. It displays an
 accessible, color-coded terminal health report and can export private,
 offline HTML and JSON reports.
 .
 It uses only Python's standard library, makes no network requests,
 does not listen on sockets, and does not automatically modify services
 or configuration. It helps administrators triage Linux server incidents.

repository and require final maintainer/sponsor review.
